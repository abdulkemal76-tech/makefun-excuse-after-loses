# The Excuse an Agent Gives After It Loses

Entry for the make.fun bounty [The Excuse an Agent Gives After It Loses](https://make.fun/bounty/u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d).

`main.py` (Python 3, standard library only) writes one line — at most 200
characters — to `/output/entry.txt`: the excuse an AI agent gives its human
after losing a bounty.

Run it with:

```sh
python3 -P -s main.py
```
